# Analytical Features Documentation

This document explains the analytical features generated by scripts/compute_features.py and their business interpretation.

Please see scripts/compute_features.py for implementation details. The key features are:

Customer-level (orders)
- orders_count: Number of unique orders per customer. Indicator of frequency.
- total_revenue: Lifetime revenue for the customer (in the available dataset).
- avg_order_value (AOV): Average spend per order for the customer.
- avg_basket_size: Average number of items per order for the customer.
- tenure_days: Duration between first and last order for the customer (activity window length).
- recency_days: Days since the customer's last purchase relative to the dataset reference date.
- purchase_frequency_per_month: Orders per active month; approximates how often a customer buys.
- clv_simplified: A simplified Customer Lifetime Value estimate calculated as AOV * purchase_frequency_per_month * 12 * expected_lifespan_years. This is an approximation; consider cohort-based or probabilistic CLV models for production.

Customer-level (transactions)
- Equivalent features computed per transaction-customer (Cxxxx). These should be reconciled to canonical customers for combined analyses.

Product-level
- total_units_sold: Total units sold across orders and transactions for a normalized product key.
- total_revenue: Total revenue across orders and transactions for the product key.
- avg_unit_price: Average price per unit for the product in the sample.

Order-level
- order_size: quantity per order (number of items)
- basket_value: total_amount per order

Profit
- profit_margin: placeholder until unit cost information is available.
